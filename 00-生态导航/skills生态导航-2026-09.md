## 九、终极安装指南

**统一安装命令**：
```bash
npx skills add <owner>/<repo> --skill <skill-name>
```
所有Skill均可通过skills CLI一行安装。Anthropic官方仓库可通过`/plugin marketplace add anthropics/skills`添加。

**推荐安装顺序（按优先级）**：
1. **第一步**：find-skills（生态入口，不装这个其他都白搭）
2. **第二步**：根据身份选装——开发者装vercel-react-best-practices + tdd + agent-browser；自媒体人装brainstorming + copywriting + social-content；办公族装pdf + pptx + docx + xlsx
3. **第三步**：进阶工作流——superpowers（完整工程方法论）+ grill-me（方案拷问）+ improve-codebase-architecture（架构体检）

**热度数据说明**：以上热度值综合自skills.sh（Vercel官方导航站，8周活跃度+安装量加权）和LinklyAI/best-skills（跨生态聚合榜单，覆盖skills.sh、ClawHub、Tencent SkillHub、GitHub及社交平台）。排行榜每日刷新，建议以skills.sh实时数据为准。
