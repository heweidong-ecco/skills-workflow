# Matt + Superpowers 双框架 Skills 安装命令

安装策略遵循你的分层架构：**Matt 层用项目内安装（可编辑、可提交 Git），Superpowers 层用插件安装（全局生效、自动更新）。**


## 一、Matt 层：项目内安装

Matt Pocock Skills 提供两种安装路径，二选一，**不要同时安装**（同时装会导致每个技能出现两份）。

### 方式一：Claude Code 插件（只读、自动更新，适合订阅而非定制）

在 Claude Code 会话中直接执行：

```
/plugin install mattpocock-skills
```

该插件已在 Claude Code 官方市场，无需先添加市场源，安装后自动接收更新。

### 方式二：npx skills CLI（写入项目目录，可编辑、可提交 Git，推荐）

在项目根目录执行：

```bash
npx skills@latest add mattpocock/skills
```

安装器会交互式让你选择要安装哪些技能、装到哪些 Agent 上。**务必勾选 `setup-matt-pocock-skills`**——这是所有其他工程技能的前置配置技能。

后续更新技能：

```bash
npx skills update
```

### 安装后的第一步

无论用哪种方式，**每个仓库运行一次**：

```
/setup-matt-pocock-skills
```

它会问你：用哪个 issue tracker（GitHub / Linear / 本地文件）、triage 标签词汇表是什么、文档保存到哪里。


## 二、Superpowers 层：插件安装（全局生效）

Superpowers 在不同平台上的安装命令不同。

### Claude Code（官方市场，推荐）

```
/plugin install superpowers@claude-plugins-official
```

这是最简洁的安装方式，无需先添加市场源。

### Claude Code（Superpowers 专属市场）

如需获取内测或定制版本，先添加市场源再安装：

```
/plugin marketplace add obra/superpowers-marketplace
/plugin install superpowers@superpowers-marketplace
```

### Cursor

在 Cursor Agent 聊天框中直接输入：

```
/add-plugin superpowers
```

或在 Cursor 插件市场中搜索“superpowers”手动添加。

### Codex

Codex 需要手动设置。让 Codex 执行：

```
Fetch and follow instructions from https://raw.githubusercontent.com/obra/superpowers/refs/heads/main/.codex/INSTALL.md
```

### OpenCode

让 OpenCode 执行：

```
Fetch and follow instructions from https://raw.githubusercontent.com/obra/superpowers/refs/heads/main/.opencode/INSTALL.md
```

### Gemini CLI

```bash
gemini extensions install https://github.com/obra/superpowers
```

更新命令：

```bash
gemini extensions update superpowers
```

### GitHub Copilot CLI

```bash
copilot plugin marketplace add obra/superpowers-marketplace
copilot plugin install superpowers@superpowers-marketplace
```


## 三、验证安装

### 验证 Matt 层

安装完成后，在 Claude Code 中执行 `/setup-matt-pocock-skills`，确认交互式配置能正常触发。输入“帮我盘问这个需求”，观察是否自动触发 `grill-me`。

### 验证 Superpowers 层

开启一个新会话，输入“帮我规划这个功能”或“调试这个问题”，Agent 应自动调用相关的 Superpowers 技能。也可以用 `/help` 检查是否出现 `/brainstorm`、`/write-plan`、`/execute-plan` 等斜杠命令。


## 四、安装后确认清单

- [ ] Matt 层：`npx skills@latest add mattpocock/skills` 已执行，`setup-matt-pocock-skills` 已勾选
- [ ] Matt 层：每个仓库运行过 `/setup-matt-pocock-skills`
- [ ] Superpowers 层：已通过 `/plugin install superpowers@claude-plugins-official` 或对应平台命令安装
- [ ] 未同时安装 Matt 的两种方式（插件 + npx 二选一）
- [ ] 技能触发验证通过（`grill-me` 和 Superpowers 执行骨架均能正常触发）
- [ ] 后续步骤：按前面的实施文档配置 `CLAUDE.md`、`.claude/rules/`、`settings.json` 和 `skill-guard.sh`
